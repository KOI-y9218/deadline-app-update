## Beta 版本

Beta 版本按主版本分组记录，后续迭代统一追加到对应分组，避免版本数量增加后表格横向扩展。

### v0.5.5.2

- **Beta1**：优化更新页面半屏展开与关闭动画、底栏隐藏与恢复时机及触摸屏蔽；增加正式版与 Beta 更新通道和更新弹窗预览测试工具；修正后台保活设置中的“无障碍”文字
- **Beta2**：统一自动更新与弹窗预览的半屏动画、底栏隐藏恢复和触摸交互时序
- **Beta3**：优化更新半屏弹出时底栏的淡出时机，使底栏与半屏入场同步

### v0.5.6

- **Beta1**：完善后台更新下载、断点续传、校验与安装状态恢复；接入 Android 官方实时更新进度通知；统一小米任务岛倒计时、计时器和逾时显示单位；修复 Release 构建启动时的后台更新初始化问题
- **Beta2**：修复主页编辑任务和日历新建任务未复用统一任务表单转场，导致视图栏、分类栏和底部导航残留并遮挡表单按钮；统一任务表单进入与返回时的原生栏隐藏、触摸屏蔽和恢复时序

### v0.5.6.1

- **Beta1**：优化设置页、任务表单和统计页的转场与渲染性能；复用静态背景缓存、任务表单帧快照和统计数据快照；统一半屏任务表单保存、删除后的退场动画、原生栏位同步、触摸屏蔽与恢复时序
- **Beta2**：优化主页、日历和统计页切换时视图栏与分类栏的出现时机；按页面转场进度同步原生栏位布局、淡入和触摸状态，减少抢跑、补显和瞬移感
- **Beta3**：修复新建任务页面退出后视图栏和分类栏未及时恢复的问题；保持原生栏位槽位挂载并按转场进度控制显隐；修复旧的 Flutter 可见快照覆盖原生淡入淡出目标导致的闪烁
- **Beta4**：将日视图日期标题切换调整为横向推入并错开淡出、淡入，减少新旧日期文字重叠；将任务区域改为可跟手分页，左右拖动时任务内容和添加任务按钮同步移动，松手后吸附到目标日期；优化下载完成后的原生灵动岛，显示“下载完成，点击安装”，展开后可直接进入系统安装器并保持前后台完成状态

### v0.6.0

- **Beta1**：新增“日刻 AI”独立入口与对话页面；支持 DeepSeek 和 Xiaomi MiMo API 配置；支持自然语言创建计划、灵活任务和 DDL，以及按空闲时间智能安排多个任务；新增任务与日程变更预览，确认后才写入；支持本地会话记录、会话切换和历史续接；优化多轮上下文、澄清选项、输入框和失败重试；修复任务意图、类型、标题、共享时长、相对日期、多任务遗漏、内部 ID 暴露及确认前错误应用问题；修复安装器未完成时更新状态卡住，导致再次点击下载没有进度或不会重新下载的问题
- **Beta2**：修复同一会话每发一条消息就隐式重试的问题；完善 Xiaomi MiMo 结构化响应、错误分类和兼容处理；改进任务类型判断、跨日期任务匹配、时间与时长预览及冲突说明；新增只读本地任务查询；修复会话恢复、消息顺序、连接检测与请求竞态问题；兼容旧版会话和任务数据，保留具体错误提示与手动重试入口
- **Beta3**：新增通过对话查找并删除任务、复制聊天消息及更多 DeepSeek/MiMo 模型选项；优化删除预览、未确认预览恢复、多轮上下文整理与输入法跟随；修复单条消息隐式重试、重复追问、旧会话迁移、任务时长/冲突说明及 Android 长截图边界；优化日历/周视图分页同步、分类与底栏恢复，并加入按模块展示的版本更新日志
